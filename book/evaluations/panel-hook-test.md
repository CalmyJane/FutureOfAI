**Winner: Package 2** (all four readers' favourite). **Runner-up: Package 1.**
Reasons given: Package 2 is the only one that puts a person and a checkable number up front ("Hanne's assistant saved her four cents. So did everyone else's."; "thirteen times what the grid was built to survive"), and the opening pays off the blurb directly. Package 1's logline ("what breaks when it goes right") is strong, but the subtitle reads as a think-tank report and "open problems for researchers" signals "not for me" to general readers (though Marcus liked it). Package 3 overclaims ("make sure it never happens") and praises itself. Package 4 has the best single idea ("all wrong together") but no person in it, and a soft TED-talk ending.
Notes: readers asked that the "two hundred million" (decisions) vs. "ninety million" (devices) figures be made explicit in copy; Marcus wanted Package 1's "open problems" line added to Package 2; "Perfectly Obedient" in Package 2's subtitle is one word too strong.
This is a simulated signal, not a market measurement.
