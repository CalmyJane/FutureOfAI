# Figure 3.3 — The training pipeline

- **type:** diagram
- **purpose:** Show the stages that turn raw text into a chat assistant and a reasoning model, with what data each stage uses and what it produces.
- **caption:** Figure 3.3: The training pipeline of a typical chat model. Pre-training on web-scale text produces a base model that continues text; supervised fine-tuning on demonstrations teaches it to follow instructions; preference training with human or AI feedback shapes its style and safety; reasoning models add reinforcement learning on problems with checkable answers. Diagram by the author, based on [@ouyang2022training; @bai2022constitutional; @guo2025deepseekr1]
- **content (left→right main row, four stage boxes with arrows):**
  1. Input cylinder (far left) "Web-scale text" (sub-label "trillions of tokens") → stage box **"Pre-training"** (sub-label "predict next token") → output pill **"Base model"** (sub-label "continues text").
  2. Input above: "Written demonstrations" → stage box **"Instruction tuning"** (sub-label "supervised fine-tuning") → pill **"Instruction model"**.
  3. Input above: two small boxes "Human rankings (RLHF)" and "Principles + AI feedback (RLAIF)" feeding a small box "Reward model" → stage box **"Preference training"** (sub-label "RL or DPO") → pill **"Chat assistant"**.
  4. Branch (dashed arrow down-right from "Chat assistant" or from "Base model"): input "Problems with checkable answers" → stage box **"Reasoning RL"** (sub-label "reward correct answers") → pill **"Reasoning model"**.
- Under the row, a thin timeline-like annotation: width of the "Pre-training" box visibly larger, labelled "most compute"; other stages labelled "far less data". (Qualitative; no numbers.)
- Layout: left→right, greyscale, short labels.
