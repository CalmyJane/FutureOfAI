# fig-11-03

- **type:** bar chart
- **purpose:** Show the size of automation bias: radiologists' accuracy collapses when a purported AI system gives a wrong suggestion, and experience reduces but does not remove the effect.
- **caption:** Figure 11.3: Percentage of mammograms rated correctly by radiologists of three experience levels when a purported AI system suggested the correct or an incorrect category. All groups were affected, the least experienced most. Error bars show ±1 standard deviation. Source: [@dratsch2023automation]
- **content:**
  - Grouped bar chart; x-axis groups (left → right): "Inexperienced", "Moderately experienced", "Very experienced"
  - Two bars per group: "AI suggestion correct" (dark grey) and "AI suggestion incorrect" (light grey / hatched)
  - Data (mean % of mammograms correctly rated; ± SD shown as thin error bars):
    - Inexperienced: correct 79.7% (± 11.7); incorrect 19.8% (± 14.0)
    - Moderately experienced: correct 81.3% (± 10.1); incorrect 24.8% (± 11.6)
    - Very experienced: correct 82.3% (± 4.2); incorrect 45.5% (± 9.1)
  - y-axis: "Mammograms rated correctly (%)", linear 0–100.
  - Data labels on bars.
  - Footnote: "27 radiologists; 50 mammograms; the 'AI' was simulated by the researchers. Error bars: ± 1 SD. All differences significant (P ≤ .003)."
  - All values from the abstract of Dratsch et al., Radiology 307(4): e222176 (2023).
