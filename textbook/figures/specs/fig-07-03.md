# fig-07-03

- **type:** bar chart
- **purpose:** Show the size of global data-centre electricity use today and the range of IEA projections for 2030, so readers see both the growth and the uncertainty.
- **caption:** Figure 7.3: Global data-centre electricity consumption, 2023–2025 (IEA estimates), and 2030 under four IEA cases. Data centres used about 1.5% of the world's electricity in 2025; the Base Case reaches about 3% by 2030. Source: @iea2026key, Annex A, Table A.1 (data published April 2026).

## content

Vertical bar chart, linear y-axis.

- y-axis: "Electricity consumption (TWh)", linear, 0 to 1,200, gridlines every 200.
- x-axis: categories in this order, with a small visual gap (or a dashed vertical separator labelled "Projections") between 2025 and the 2030 bars.

| Category | Value (TWh) | Source |
|---|---|---|
| 2023 | 360 | iea2026key, Table A.1 (Base Case column, historical) |
| 2024 | 416 | iea2026key, Table A.1 |
| 2025 | 485 | iea2026key, Table A.1 |
| 2030 Headwinds | 833 | iea2026key, Table A.1 |
| 2030 High Efficiency | 868 | iea2026key, Table A.1 |
| 2030 Base Case | 945 | iea2026key, Table A.1 |
| 2030 Lift-Off | 1,008 | iea2026key, Table A.1 |

- Historical bars (2023–2025): solid dark grey. 2030 bars: hatched or light grey, Base Case outlined more heavily.
- Value labels on top of each bar.
