# fig-05-01

- **type:** diagram
- **purpose:** Show that an agent is a loop around a model, not a single question-and-answer exchange, and where memory, tools and human intervention fit.
- **caption:** Figure 5.1: The basic agent loop. A language model receives a goal, plans a step, calls a tool, observes the result and repeats; memory carries information between steps, and the loop ends when the goal is met, a limit is reached or a human intervenes. Diagram by the author.
- **content:**
  - Layout: a circular (clockwise) loop in the centre, with an input box on the left and an output box on the right; memory below the loop; tools above the loop.
  - Left input box: "Goal from user".
  - Arrow from "Goal from user" into the loop at the "Perceive" node.
  - Loop nodes (clockwise, four rounded boxes):
    1. "Perceive" (small subtitle: "read current state")
    2. "Plan" (subtitle: "model chooses step")
    3. "Act" (subtitle: "call a tool")
    4. "Observe" (subtitle: "read tool output")
  - Arrows: Perceive → Plan → Act → Observe → Perceive.
  - Centre of loop: label "Language model" (the Plan node sits closest to it; a thin line connects "Plan" to "Language model").
  - Above "Act": a box "Tools" containing four small items: "Web search", "Code runner", "Email", "Files". Two-way arrow between "Act" and "Tools".
  - Below the loop: a box "Memory" (subtitle: "notes, transcript"). Dashed two-way arrows from "Memory" to "Plan" and to "Observe".
  - Right output box: "Stop: goal met / limit reached". Arrow from "Observe" to this box labelled "done?".
  - A small human icon or box "Human check" at top right, with a dashed arrow to the "Act" node labelled "approve / interrupt".
  - Greyscale, line style; no colour coding needed.
