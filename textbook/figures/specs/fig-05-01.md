# fig-05-01

- **type:** diagram
- **purpose:** Show that an agent is a loop around a model, not a single question-and-answer exchange, and where memory, tools and human intervention fit.
- **caption:** Figure 5.1: The basic agent loop. A language model receives a goal, plans a step, calls a tool, observes the result and repeats; memory carries information between steps, and the loop ends when the goal is met, a limit is reached or a human intervenes. Diagram by the author.
- **content:**
  - Layout: a clockwise rectangular loop of four boxes (Perceive top left, Plan top right, Act bottom right, Observe bottom left), with the input box on the left, memory inside the loop, the language model above Plan, tools to the right of Act, the human check to the right of Plan and the stop box below Observe. (As drawn; supersedes the earlier circular layout.)
  - Left input box: "Goal from user".
  - Arrow from "Goal from user" into the loop at the "Perceive" node.
  - Loop nodes (clockwise, four rounded boxes):
    1. "Perceive" (small subtitle: "read current state")
    2. "Plan" (subtitle: "model chooses step")
    3. "Act" (subtitle: "call a tool")
    4. "Observe" (subtitle: "read tool output")
  - Arrows: Perceive → Plan → Act → Observe → Perceive.
  - Above "Plan": a box "Language model", joined to "Plan" by a thin line (the model is the component that chooses each step).
  - Right of "Act": a box "Tools" containing four small items: "web search", "code runner", "email", "files". Two-way arrow between "Act" and "Tools".
  - Inside the loop: a box "Memory" (subtitle: "notes, transcript"). Dashed two-way arrows from "Memory" to "Plan" and to "Observe".
  - Output box below "Observe": "Stop: goal met or limit reached". Arrow from "Observe" to this box labelled "done?".
  - A box "Human check" at right, beside "Plan", with a dashed arrow to the "Act" node labelled "approve / interrupt".
  - Greyscale, line style; no colour coding needed.
