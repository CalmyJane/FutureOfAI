# fig-04-03

- **type:** scatter (time on x, log-scale y) with error bars
- **purpose:** Show the growth of METR's 50% task time horizon for frontier AI models from 2019 to 2026, the speed of that growth, and the wide uncertainty for the most recent models.
- **caption:** Figure 4.3: METR's 50% task time horizon for AI models that set a new record when released, 2019–2026, on a logarithmic scale. The time horizon is the length of software task, measured by how long it takes a skilled human, that a model completes with 50% predicted success. Error bars show METR's bootstrapped confidence intervals. METR states that measurements above 16 hours are unreliable with its current task suite. All points are Time Horizon 1.1 except the three earliest (GPT-2, GPT-3 and GPT-3.5), which METR carried over from Time Horizon 1.0. Source: @metr2026task.
- **content:**

Values are p50_horizon_length estimate and confidence interval (ci_low, ci_high; the data file does not state the level, METR's paper uses 95% bootstrapped intervals) in MINUTES, copied exactly.
