# Figure 2.3: Gradient descent as walking downhill

- **type:** diagram (schematic line chart)
- **purpose:** Give the "walking downhill in fog" intuition: the loss depends on the weight, each step moves against the slope, and the learning rate determines whether steps converge or overshoot. Uses the chapter's worked example shape (minimum at weight 0.5).
- **caption:** Figure 2.3: Gradient descent pictured as walking downhill. The curve shows how the loss (vertical axis) changes as one weight (horizontal axis) changes. Starting from a random weight, each step moves against the slope; a moderate learning rate approaches the minimum, while a learning rate that is too large overshoots to the other side. Real networks have millions of weights, so the true landscape has millions of dimensions. Schematic, not to scale. Diagram by the author.
- **content:**
  - A single U-shaped curve (parabola), x-axis "Weight", y-axis "Loss". No numeric tick labels needed except optional marks at the starting point and minimum.
  - Lowest point marked with a small open circle and label "minimum (lowest loss)".
  - Left side of the curve: a filled dot labelled "start" (corresponds to weight 0.2 in the text).
  - Path A (solid arrows): three short arrows hopping along the curve from "start" toward the minimum, each shorter than the last, labelled "moderate learning rate".
  - Path B (dashed arrow): one long arrow jumping from "start" across the minimum to a point high on the right side of the curve, labelled "too large: overshoots".
  - A short tangent line drawn at "start" with label "slope = gradient".
  - Optional small inset in top right corner: a contour-map sketch (concentric ellipses) with a zig-zag path to the centre, labelled "two weights, seen from above".
  - Greyscale; path B in a lighter grey dashed style.
