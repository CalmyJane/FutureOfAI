# Figure 2.3: Gradient descent as walking downhill

- **type:** diagram (schematic line chart)
- **purpose:** Give the "walking downhill in fog" intuition: the loss depends on the weight, each step moves against the slope, and the learning rate determines whether steps converge or overshoot. Uses the chapter's worked example exactly: input 2, target 1, loss (2w − 1)², minimum at weight 0.5; all marked points computed by the author.
- **caption:** Figure 2.3: Gradient descent pictured as walking downhill. The curve shows how the loss (vertical axis) changes as one weight (horizontal axis) changes, for the worked example in the text, whose minimum is at weight 0.5. Starting at weight 0.2, each step moves against the slope; a learning rate of 0.1 closes 80% of the remaining gap per step, while a learning rate of 0.5 overshoots to 1.4, where the loss is higher than at the start. Real networks have millions of weights, so the true landscape has millions of dimensions. Diagram by the author.
- **content:**
  - A single U-shaped curve (parabola) L(w) = (2w − 1)², x-axis "Weight" (range about 0 to 1.5), y-axis "Loss" (range 0 to about 3.5). Tick marks at weights 0.2, 0.5 and 1.4.
  - Lowest point marked with a small open circle and label "minimum (lowest loss)".
  - Left side of the curve: a filled dot labelled "start" (corresponds to weight 0.2 in the text).
  - Path A (solid arrows): three arrows along the curve from "start" (w = 0.2, loss 0.36) to w = 0.44 (loss 0.0144), then 0.488, then 0.4976, each shorter than the last, labelled "learning rate 0.1".
  - Path B (dashed arrow): one long arrow jumping from "start" across the minimum to w = 1.4 (loss 3.24) on the right side of the curve, labelled "learning rate 0.5: overshoots".
  - A short tangent line drawn at "start" with label "slope = gradient".
  - Optional small inset in top right corner: a contour-map sketch (concentric ellipses) with a zig-zag path to the centre, labelled "two weights, seen from above".
  - Greyscale; path B in a lighter grey dashed style.
