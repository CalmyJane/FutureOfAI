# Figure 2.3: Gradient descent as walking downhill

- **type:** diagram (schematic line chart)
- **purpose:** Give the "walking downhill in fog" intuition: the loss depends on the weight, each step moves against the slope, and the learning rate determines whether steps converge or overshoot. Uses the chapter's worked example exactly: input 2, target 1, loss (2w − 1)², minimum at weight 0.5; all marked points computed by the author.
- **caption:** Figure 2.3: Gradient descent pictured as walking downhill. The curve shows how the loss (vertical axis) changes as one weight (horizontal axis) changes, for the worked example in the text, whose minimum is at weight 0.5; the right-hand panel enlarges the boxed region near the minimum. Starting at weight 0.2, each step moves against the slope; a learning rate of 0.1 closes 80% of the remaining gap per step, while a learning rate of 0.5 overshoots to 1.4, where the loss is higher than at the start. Real networks have millions of weights, so the true landscape has millions of dimensions. Diagram and calculation by the author; gradient descent as in @goodfellow2016deep [sec. 4.3, fig. 4.1].
- **content:**
  - Two panels side by side, both plotting L(w) = (2w − 1)², x-axis "Weight w", y-axis "Loss"; all marked points computed (and asserted) in the drawing code.
  - **Left panel (whole curve):** w from about 0 to 1.5, loss 0 to about 3.5; ticks at weights 0, 0.2, 0.5, 1, 1.4 and losses 0–3. Filled dot "start" at w = 0.2 (loss 0.36); open circle "minimum" at w = 0.5. Path B (dashed, mid grey, curved arrow): one jump from start across the minimum to w = 1.4, labelled "learning rate 0.5: overshoots" and "w = 1.4, loss 3.24". A dotted box around w 0.15–0.53, loss 0–0.5 marked "close-up →".
  - **Right panel (close-up of the boxed region):** ticks at weights 0.2, 0.44, 0.5 and losses 0, 0.36. Path A (solid arrows): from start (0.2, 0.36) to 0.44 (loss 0.0144), then 0.488 (loss 0.000576), then 0.4976, each step shorter than the last; the last step is too small to carry an arrowhead at print size, so points 0.488 and 0.4976 are labelled together. Label "learning rate 0.1: each step closes 80% of the gap".
  - A short tangent at start, labelled "slope = gradient = −2.4".
