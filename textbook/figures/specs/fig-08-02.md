# fig-08-02

- **type:** scatter (horizontal dot-and-whisker plot, two panels)
- **purpose:** Let readers compare effect sizes across the main productivity studies, see the uncertainty around them, and notice that results range from large gains to slowdowns depending on setting, sample and tool.
- **caption:** Figure 8.2: Estimated effects of AI assistance in selected studies, with data collected between 2020 and 2025. Panel A shows changes in the time needed to complete tasks (negative values mean faster work); Panel B shows changes in output (positive values mean more output). Bars show 95% confidence intervals where the study reports them. Studies differ in design, sample, task and tool, so the estimates are not directly comparable. Source: noy2023experimental; peng2023impact; becker2025measuring; metr2026changing; brynjolfsson2025generative; dellacqua2026navigating; cui2026effects.

## content

Two vertically stacked panels sharing the same style. Each row = one study; a dot for the point estimate and a horizontal whisker for the 95% CI where available (no whisker where not reported). A vertical reference line at 0 in each panel. Linear scale. Row labels on the left in the form "Study (design; n; data year)". Use a filled circle for randomised trials and an open circle for the quasi-experimental study; legend: "● randomised  ○ quasi-experimental".
